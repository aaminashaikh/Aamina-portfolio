# Aamina Shaikh — Portfolio

Personal portfolio website for **Aamina Shaikh**, a BCA graduate and aspiring IT professional, built to showcase her profile, skills, projects, education and contact information.

**Live Demo:** https://aaminashaikh.github.io/Aamina-portfolio/
**Repository:** https://github.com/aaminashaikh/Aamina-portfolio

## About

Aamina is a BCA graduate with hands-on experience in HTML, CSS and JavaScript, and a growing interest in AI-assisted development. She's currently open to entry-level opportunities in Web Development, Software Development, Frontend, Full Stack, Python, SQL/Database, Data-related and other technology roles.

## Technologies

- HTML5
- CSS3
- JavaScript (vanilla)
- [Bootstrap 5](https://getbootstrap.com/) — layout & components
- [Bootstrap Icons](https://icons.getbootstrap.com/) — iconography
- [Google Fonts (Manrope)](https://fonts.google.com/specimen/Manrope) — typography

No build step or package manager is required — it's a static site.

## Features

- Responsive, mobile-first layout across all sections
- Sections: Home, About, Skills, Projects, Education, Contact
- Scroll-reveal animations and scroll-spy navigation highlighting
- Sticky navbar with shrink-on-scroll effect and a mobile menu
- Client-side validated contact form (not yet wired to a backend/email service)
- Downloadable resume (PDF)
- Basic on-page SEO: descriptive title/meta tags, Open Graph tags, canonical URL, `robots.txt`, `sitemap.xml`, and Person structured data (JSON-LD)

## Running Locally

This is a static site — no build tools needed. Open `index.html` directly in a browser, or serve the folder with any static file server, e.g.:

```bash
npx serve .
```
